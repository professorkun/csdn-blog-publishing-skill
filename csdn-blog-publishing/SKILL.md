# CSDN 博客写作与发布

将真实排障或开发经验写成可以公开阅读的文章。重点保留可复用的解决过程，不把私人环境变成文章的一部分。

## 写作与脱敏

- 先区分已验证的事实、推断和待长期观察项；问题背景简短，重点说明判断、处理和验证。
- 不展示私人 Wiki 的真实路径、目录、文件名、页面内容、任务 ID 或任务正文。
- 不展示 NAS 的真实主机名、内网地址、端口、账号、域名、日志、备份位置、服务配置或任何凭据。
- 示例代码使用通用文件名、模拟数据和替代任务文本，并在文章中注明“脱敏示例”。不要复制生产脚本、原始日志或配置片段。
- 使用自然、通俗的中文。代码按“目的 → 最小片段 → 说明或预期输出”分步展示，而不是整段粘贴完整脚本。
- 日常草稿阶段只快速检查明显的账号、凭据、内网地址、真实路径、私人截图和未经验证的结论；未准备提交时，不要求完成公开页验收或副本校验。

## 草稿工作流

1. 根据可追溯证据起草标题和正文；对代码、输出、图片和标题逐项做脱敏检查。
2. 写入 CSDN 编辑器前，确认当前文章内容已被用户认可；编辑器自动保存只能描述为“草稿已自动保存”。
3. 准备提交审核、发布或修改已公开文章时，复核标题、正文、代码渲染、输出示例、图片、分类、标签、可见范围和引用链接；检查正文、代码、命令、日志、截图、外链和可见附件中没有凭据、个人隐私、内网地址、真实部署路径或未授权内部信息。
4. 推断和未验证内容必须明确标注。对截图、图片和附件先检查可见内容；来源文件包含个人或内部信息时，再按需检查文件名、元数据和嵌入信息。无法检查时，标记为“未完成检查”，不得声称已完成脱敏。
5. 发现疑似敏感信息、事实状态不明或权限不清时，必须停止后续提交动作，标记为“待脱敏修订”或“待核验”，并向用户报告阻断原因；不得继续执行外部写入。

## 发布状态与证据

按下列状态记录文章进度；后一状态不能由前一状态推断。

1. `草稿/自动保存`：本地文件或编辑器内容可见。
2. `已准备提交`：发布前检查已完成，尚未发生外部提交。
3. `已提交审核`：平台已接收投稿，有提交结果、文章 ID 或后台记录。
4. `后台显示已发布`：内容管理页显示文章已发布。
5. `公开页已验证`：公开 URL 可访问，且完成最小渲染检查。

“后台显示已发布”不等于“公开页已验证”。公开页受登录、缓存、地区或平台权限影响而无法核对时，记录为“公开页待验证”；不要据此断定发布失败或公开效果已验证。

## 发布边界

- 点击“提交审核”或“发布”、修改已公开文章及外部同步都是外部写入。每一篇文章都必须在即将执行前取得用户针对当前草稿的明确确认；检查通过、过往授权或“继续写”不等于本次外部写入授权。
- 发布后至少核对公开 URL 可访问、标题与正文完整、代码块正常渲染、图片可加载、外链可打开且不指向内部环境、分类/标签/可见范围正确；记录公开链接、文章 ID、核验时间和未验证项。截图只在异常、争议或用户明确要求时保存。
- 无法完成公开页核对时，只报告对应的已知状态和“公开页待验证”，不要宣称已公开生效。

## 文章配图（可选）

- 配图不是文章完成的必需项。只有图片能明显帮助理解抽象概念、使用场景或文章结构时才生成；文字、代码、Mermaid、SVG 或真实截图已经足够清楚时，不额外生成。图片数量根据文案的信息密度、概念转换、阅读节奏和每张图带来的明确理解收益决定，不设固定上限；每张图都必须服务于具体的解释或导航需求，不得为增加视觉密度插入重复或无新信息的图片。
- 可使用封面/主题引导图、概念解释插图、少量非精确信息图或长文章节过渡图。图片放在摘要后、概念首次解释后或对应章节附近，并配简短图注；技术示意图标注“示意图；具体实现以正文代码或实测为准”。
- 不使用 ImageGen 生成代码、命令、日志、SQL、表结构、精确架构图、端口/字段/版本号、真实性能图表、测试结果或平台状态。它们应使用代码、Mermaid、SVG、确定性图表或真实截图。
- 普通新图默认使用内置图像生成工具；不主动切换 API 或 CLI。提示词、参考图和输出图不得含 Token、Cookie、账号、真实路径、内网地址、私人截图、未脱敏日志或未验证结论。使用用户提供图片前，确认用户有权使用且已完成脱敏。
- 生成图中的文字、节点、箭头、数字、设备、品牌和界面默认不具备事实效力，必须人工逐项核对。无法保证准确时，要求生成无文字概念图，并把准确说明放在正文、图注或确定性图表中；生成图不得用于证明性能、兼容性、部署状态或测试结果。
- 生成后检查隐私、构图、文字、技术误导、品牌/人物/界面、水印和禁止项。只将最终选定图片复制到本篇文章已确认的资产目录，使用不覆盖的版本化文件名；未选中的变体不进入文章资产目录。
- 生成或本地插入图片不构成 CSDN 提交、发布、修改公开文章或外部同步授权。发布后按现有公开页验收规则额外检查图片加载、尺寸比例、图注和排版；图片异常或公开页无法访问时，不得标记为“公开页已验证”。

## 与私人 Wiki 的记录

当用户要求归档或已有约定需要维护私有记录时，更新最具体的过程记录、关联待办及维护日志。写入前核对基线哈希，记录时不要把凭据或内部环境信息带入公开内容。

## Skill 副本维护

安装版、私有归档版和公开仓库版用途不同。仅在修改或同步 Skill 时，先确认目标副本和基线哈希，修改后重新计算哈希并核对副本一致性。无法读取副本、无法计算哈希或哈希不一致时，记录为“副本未同步/未完成检查”；哈希一致只说明文件内容一致，不代表 Skill 已安装、已加载或已生效。
